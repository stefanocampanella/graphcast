At the start of the week, training jobs on JUPITER failed one after the other (multi-node meshes, loss dtype, missing coordinates), and once they ran, the model skipped its message passing.
Today a 1-node training step takes 0.47 s with the GPUs 94 % busy, and throughput scales nearly linearly to 4 nodes.

  • Only zarr v2 with 8 Grain workers × 2 threads keeps the GPUs fed; every other format or loader setting leaves them waiting for data.
  • XLA/JAX tuning flags make no difference; disabling InfiniBand costs 5–10 % on 2 nodes.
  • 16 message passing steps (original GraphCast) cost only ~15 % more than 8 on the coarse mesh; the fine mesh does not fit in GPU memory.
  • 50 levels: at most 2 Grain workers fit in host memory, so training is loader bound.

For reference: original GraphCast ≈ 7.70 s/step (32 TPU v4); our Leonardo PoC ≈ 2.0 s/step on 8 nodes (different configuration).

Multi-node meshes and mixed precision

One mesh helper for all nodes


# jax.make_mesh rejects meshes spanning several GPU
# nodes, which JAX treats as separate slices.
def _make_hybrid_mesh(axis_names, local_shape, process_shape):
  devices = mesh_utils.create_hybrid_device_mesh(
    local_shape, process_shape, process_is_granule=True)
  return Mesh(devices, axis_names,
              axis_types=(AxisType.Explicit,) * len(axis_names))

def make_batch_mesh() -> Mesh:
  return _make_hybrid_mesh(("batch",),
    (jax.local_device_count(),), (jax.process_count(),))

Caveat: benchmark jobs slow each other down

  • 16 jobs that started at 09:51: 0.47 s per step.
  • 46 jobs that started at 10:13, while ~70 I/O jobs read /e/scratch: 0.88 s, with the same median compute.
  • One rank waits for data; the others wait for it in the all-reduce, which rank 0 logs as compute.
  • So: compare jobs that ran together, and look at the longest wait of any rank.

Lessons and next steps

Lessons

  • Check the model computes: step time that ignores model size is a red flag.
  • Verify what reaches the container: environment variables, flags, CPUs.
  • Measure all ranks: one rank's stall looks like everyone's compute.
  • Benchmarks interfere on a shared file system.

Next steps

  • Reduce host memory of the training process (480 GB per node) to fit more loader workers at 50 levels.
  • Fit the fine mesh: rematerialization, model or pipeline parallelism.
  • Full training run (40 000 steps) and rollouts.
  • Data on node-local or faster storage to isolate jobs from each other.
